# 02 · 两轮提问

提问服务于决策，不服务于清单。"字段齐了"不等于"产品懂了"。

## 对话呈现与衔接

遵守主 Skill 的苏格拉底提问规则：把完整问题直接写进最终回复正文，用户在聊天回复框中作答，不调用弹出式提问工具。

- 保留题号、优先级、必要的事实或草稿原句，以及不同答案影响的具体文案。不要在回复中只给问题简写，再让用户打开文档找依据。
- 用户可以按题号回答，也可以连续自然语言回答；主智能体负责对应题号。接受“不清楚 / 跳过”，不要求点击选项、填写表单或提交按钮。
- 提问后正常结束当前回复，等待用户在对话中回答；明确当前停在本轮提问，不把这一停顿说成整个任务完成。
- 收到答案后按既定流程继续，必要追问仍在回复正文中展示。问题与答复可以落盘归档，归档文件不承担交互入口。

第一轮收尾示例：**“请直接在回复框按 A1、A2……回答，也可以写‘不清楚’或‘跳过’。收到后，我会合成产品意图与事实台账，再进入独立写稿。”**

第二轮收尾示例：**“请直接在回复框按 Q1、Q2……回答。收到后，我会落实这些决定并交付定稿。”**

## 第一轮：把基础打牢，再问设计初衷

发出时机：预研三员汇总完成后，一次发全。老板回答前不写任何消费者文案。

### 只问什么

- 台账里状态为 **未知 / 冲突** 且会改变买家决策的项。
- 页面自相矛盾处：给出双方原文，问哪个对。
- 已知项列为"请确认：____（来源）"，不重问。

### 必须覆盖的领域（有缺口才问，没缺口就列"请确认"）

身份 · 版本 · 变体 · pack ｜ 材料与工艺 ｜ 结构与部件 ｜ 尺寸与适配（含尺码表准不准、偏大偏小）｜ 配件（含不含、能不能自己加）｜ 功能与限制（能做什么、明确不能做什么）｜ 用法（单手能否操作、步骤）｜ 用途与场景 ｜ 洗护与耐久（洗标原文）｜ 包装 ｜ 销售与退货事实（哪个码最好卖、退货主因）｜ 产地。

### 末尾固定三题（每个产品都问）

- **设计初衷**：这个产品最初要解决什么问题？当时买家怎么凑合？为什么选这个形态（而不是别的）？为此接受了什么取舍？
- **改版史**：改过什么、为什么改（尺码、面料、扣具、供应商）。
- **多年销售事实**：哪类人最满意、哪类人退货、差评集中在什么、好评里反复出现的词。

### 分级与格式

A（误购 / 安全 / 身份）→ B（改变主购买理由）→ C（局部补充）。编号独立，一题一个答案单元。每题模板：

```
A3. 胸垫到底含不含？
已知：五点写"pads not included"（F31，仅观察）；Product Summary 写"6pcs pads"（F32，仅观察）。
缺：一手确认。
不同答案改变什么：含 → B3 写成配件卖点；不含 → B3 写成"有理由的选择"并删 Summary 旧句。
```

允许"不清楚 / 跳过"。不清楚 → 员工核实任务：`谁 / 怎么查 / 拿到什么算完成 / 影响哪句`。跳过 → 不争论，按台账现状处理，缺口进发布前检查。

### 提问质量自检

发出前逐题问自己：这题的答案会不会改变某一句文案？不会 → 删。答案能不能自己查到？能 → 自己查，改为"请确认"。是不是在问老板做竞品分析？是 → 删，那是竞对员的活。

## 第二轮：只问草稿分歧

发出时机：评审与裁决之后，定稿之前。

### 只问什么

评审后仍存在、**草稿之间真实分歧**、且**只有老板能拍板**的事：客户真实用法比例、哪类人更满意、哪种承诺敢不敢做、素材预算、敏感事实（换供应商、旧差评）愿不愿公开写。

不问：能自己查的、评审已经判出胜负的、只影响一个形容词的。

### 格式（每题必附原句）

```
Q1. 支撑边界要不要公开写？
A 稿（B2）："If you usually wear DD or up and want firm lift, this is not that top."
B 稿：不写边界，只写 "light, wire-free support"。
依据：模拟买家 Morgan（不该买的人）读 A 稿第 4 句就自己退出；读 B 稿到 Description 才发现。Jess（主力）对 A 稿无反感。
你的客户实际更像哪种？你的回答会改变：B2 全句、A+ 正文一句、Description 一段。
```

老板跳过 → 主智能体按研究推荐，标注"假设"，继续定稿。

### 第二轮题量（参考值，不是硬规定）

通常 5–8 题。超过 10 题说明裁决没做完；少于 3 题说明四稿没有真正分化。

## 老板回答的处理

1. 写进 `04_fact_ledger_v1_delta.md`（第一轮）或 `09_final_locked.md` 决策记录表（第二轮）：问题 → 回答原文 → 改了哪些句子。
2. 老板口述但无书面证据的事实（"去年换了扣具供应商"）：升 CANDIDATE，不升 SAFE；进 Q&A / 差评回复模板，不进 Title / 五点。
3. 老板的判断（"标题不要写 Unpadded，会降转化"）：直接执行，记录理由；不用评审结果反驳。
4. 老板"不知道，你看图"：主智能体看图判断，标"仅观察"。
