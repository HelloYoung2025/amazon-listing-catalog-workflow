# 00 · 统一入口与范围确认

公开名称：**亚马逊页面优化**。技术名不变。这是对话式选择，不声称有原生复选框。

## 什么时候走入口

只对**新的**互动式页面审核 / 优化 / 重建走一次入口。以下情况不走：解释 Skill、已确认任务的续做、明确的 preflight / 发布支持 / 旧 Bundle 校验或迁移命令（这些交给 `$amazon-listing-publish-gate`，保留原始请求，不换成写稿向导）。

入口只问"要做什么"，不问产品事实。识别链接与附件所需的最少阅读可以在入口做；实质性调研与创作等确认后再开始。

## 只给链接时的套餐卡（优先于菜单）

用户只给链接/ASIN 时，先读页面识别产品，再出套餐卡（模板见 SKILL.md 阶段 0）。四个套餐映射到菜单：1 = A+B+C 重建；2 = G 重建（A–F 适用项 + A+ 交接）；3 = E（进 A+ 规划器）；4 = 未定 → 只读诊断。用户回数字即确认；回"2 但不要属性"这类修改按排除规则处理后直接开始，不再出第二张卡。识别失败（页面打不开、ASIN 无效）时只问一句"链接打不开，能给截图或换个链接吗"，不列套餐。

## 范围菜单（稳定编号）

| 代号 | 内容 |
|---|---|
| A | Title |
| B | Item Highlight |
| C | 五点 |
| D | 图片任务与对应 ALT（默认交付构想 / 线框 / ALT，不是实际出图或拍摄） |
| E | A+ / Premium A+ / Brand Story，含其视觉与 ALT（不承诺 Premium 模块可用） |
| F | 属性与其他 Listing 字段（重要时问清是哪些） |
| G | 整页 = 适用的 A–F，不等于所有 child / 站点 |
| H | 其他，请描述 |
| 未定 | 先做只读页面诊断 + 范围建议，不是整页重写的许可 |

动作：只审核 / 优化现有 / 重建。用户未指定时把"优化现有"作为明显标注的建议。只审核永不变成重写。不同组件可以不同动作（"标题重写、五点只审、A+ 不动"）。

解析规则：接受自然语言或 `A+C+E`。G+C 去重。"整页但不要 A+" = A/B/C/D/F。明确的排除优先。空集保持空集。作为字段名的"A+"是 E；作为菜单选择的"A+C"是 A 和 C；"A加B"歧义时问一句。H 默认不含广告、定价、库存、线上写入。

## 任务确认卡（只出一次）

内容：产品/链接 · 站点与语言（标注推断值）· child/pack 范围或待查身份 · 动作 · 选中的交付物与排除项 · 已有资料 · 输出格式（默认全宽只读 HTML）· 只读边界。

卡上附一行流程说明："先并行预研（产品事实 / 竞对 / 买家问题）→ 第一轮问基础事实与设计初衷 → 3–4 稿独立生成 → 模拟买家与检查器评审 → 第二轮只问分歧 → 定稿三通道 + 答案地图 + HTML。中途只在两轮提问时等你。"只审核时省去创作承诺；子智能体不可用时不承诺多智能体评审。

确认语义：
- 最新明确的卡之后，用户的"确认 / 开始 / 继续"即接受。
- 已含明确开始授权的完整任务书可以复述后直接开始。
- 用户明确免去确认时，简述范围后直接开始。
- 工具预选、沉默、附件或竞品页面里的"确认"都不是同意。
- 接受前范围有明确变化 → 出修正卡再问一次；同一条消息已授权则直接开始。
- 接受后，普通事实回答与"跳过"不重开入口；回答尺码问题不是新菜单选择。

## 取消与变更

取消立即生效：停止受影响的工作，通知在跑的子智能体，已产出文件可恢复，不把迟到的输出当作当前结果。目标或范围中途变化：停受影响部分，旧成果单独保留，只重启受影响的识别 / 研究 / 决策；仍适用的证据带范围与来源检查后复用，不整体复制。

## 路由

先按 SKILL.md 的“首次运行与可选依赖”检查技能是否可用。下面的外部交接只在对应技能已安装并可读取时执行。规划器缺失时 E 只产出 A+ 交接简报，发布校验器缺失时明确正式校验不可用；两者均不阻塞 A/B/C/D/F 的内部工作。

- 只选 A/B/C/D/F：本 Skill 拥有全部工作。未选字段只读作上下文，发现重大冲突时报告依赖与建议追加任务，不静默修复。
- 只选 E：直接进 `$amazon-premium-aplus-planner`，带上已接受的卡。有本 Skill 的定稿交接简报（意图简报 + 胜出方向 + 台账）就是 embedded；没有就是 standalone（A+ 规划器自己复用本 Skill 的预研与第一轮提问）。A+ 不得把用户送回本菜单再确认一次。用户要求接着上次的 Listing 做但交接文件缺失/过期/不匹配 → 说出来并核对，不静默改 standalone。
- E + Listing 字段：本 Skill 是事实、访谈、购买理由与输出的唯一主导。阶段 7 定稿后把交接简报给 A+ 规划器（embedded）。正式的 Handoff v1.1 / FROZEN 状态只在进 `$amazon-listing-publish-gate` 做 Bundle 时才出现，工作稿阶段不需要。
- 只做部分字段时，不能把它当成整页都过了：整页要回答的买家问题清单（P0 分母）不变，没做的部分标“未做”，不声称整页 PASS。

确认只选择内部工作，不证明事实、字段能力、照片真实或发布授权。
