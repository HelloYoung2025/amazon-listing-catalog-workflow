# 01 · 预研三员与事实台账

预研的目的：**在问老板任何问题之前，自己先把产品和市场调查清楚**。老板只回答调查回答不了的事。

## 工作目录

每个产品建一个目录（如 `<产品代号>_rebuild_<日期>/`），所有阶段文件按序号落盘，UTF-8：

```
inputs/                     附件、后台截图、历史问答、旧文案（旧文案只作失败样本）
00_fact_ledger_v0.md        产品调查员
01_competitor_teardown.md   竞对拆解员
02_buyer_question_bank.md   买家问题挖掘员
03_synthesis_and_round1_questions.md
04_fact_ledger_v1_delta.md  老板第一轮回答后的台账增量 + SAFE/CANDIDATE/HOLD 三档
BRIEF_copywriter.md         文案员共同任务书
05_draft_W1..W4.md
06_blind_copy_pack.md       匿名英文文案包（给买家评审）
07_buyer_<name>.md / 07_truth_check.md / 07_rules_check.md
08_round2_questions.md
09_final_locked.md + <产品>_首屏优化稿_<版本>_<日期>.html
```

## 三员并行，互不可见

### 产品调查员

输入：链接（含每个 child 的前台）、附件、后台截图、历史问答、旧文案。不看竞品。

任务：
1. 抄录当前页面全部可见内容：Title、Highlight、五点、描述、属性、图片文字、A+、Brand Story、尺码表、Q&A、Product Summary。按 child / pack 分行。
2. 对每条信息判状态：**已证**（有可核对的一手来源：后台字段、吊牌/洗标/实物照、规格书、老板明确书面答复）/ **仅观察**（页面或旧文案写着，但无一手来源）/ **冲突**（两处说法不一致，列出双方）/ **未知**（买家会问但哪里都没说）。
3. 列出页面自相矛盾清单（例：五点说无垫、Product Summary 说送 6 片垫；前台尺码表与 A+ 尺码表不一致；三个 child 面料字段不统一）。
4. 每条事实标"影响哪个买家问题"（对接问题库的 Q_id，可以先用文字）。

输出格式：

```
| fact_id | 内容 | 状态 | 来源定位 | 适用 child/pack | 影响的买家决策 |
| F01 | 面料 94.8% nylon 5.2% spandex | 已证 | 后台 fabric_type 字段截图 2026-09-07 | 全部 | 材质/透气/贴身 |
```

统计一行：已证 n / 仅观察 n / 冲突 n / 未知 n。

### 竞对拆解员

输入：品类主词、目标 ASIN（只为排除自己）。不看本品后台。

任务：
1. 找 5–8 个直接竞品（同品类、同价格带 ±50%、同 pack 结构优先）和 2–3 种替代方案（买家不买这类产品时怎么凑合：别的品类、DIY、什么都不买）。
2. 每个竞品记：Title 主张、Highlight、五点主张、价格带、pack、材质、1★ 抱怨原话（≥3 条）、5★ 夸赞原话（≥3 条）、Q&A 高频问题、图片与 A+ 讲了什么、**没讲什么**。
3. 输出"共有 / 差异"矩阵，结尾指出**真正分叉的 2–3 条轴**（所有人都在讲的不是分叉）。
4. 竞争取舍表初稿四类：有依据的相对优势 / 有依据的相对不足 / 共有但对买家重要 / 未知或不可比。每条注明依据来自哪个竞品页面或评论。
5. 竞品内容缺口：买家在问、同行都没答的问题（这是本品最便宜的差异化机会）。

### 买家问题挖掘员

输入：本品与竞品评论、Q&A、搜索框联想、论坛/社群帖（Reddit、妈妈群、品类 FAQ 等公开可访问来源）。不写文案。

任务：
1. ≥30 条买家原话问题，每条标：来源、频率（高/中/低）、决策影响（决定买不买 / 决定买哪个 / 只是好奇）、类型（**选对**类 vs **排除**类）。按 频率 × 决策影响 排序。
2. 抱怨与夸赞原话各 ≥10 条，标情绪触发点（哪个词让人失望或惊喜）。
3. 搜索联想词（亚马逊搜索框 + Google），按出现位置记录；反向需求词单列（如"without built in bra"）。
4. 2–3 个人设草案：**主力买家**（最常见成功购买者）、**不该买的人**（最常见退货者，他进页面时带着什么误解）、**挑剔比价者**（会看 Q&A、看差评、开两个标签页比）。每个人设写"进页面时带着的 3–5 个问题"。

## 主智能体汇总（写入 03）

1. 《产品认识 v0》：一段话说清这是什么、给谁、解决什么、目前页面怎么说的。
2. 页面问题清单：冲突 + 缺失，按对买家的伤害排序。
3. 竞争取舍表初稿（来自竞对员）。
4. 问题库前 15 条（来自挖掘员），每条标当前页面有没有回答、在哪回答。
5. 第一轮题包（见 02）。

## 复用规则

竞品来源缺失只限制依赖它的比较，不阻塞任何基础澄清。历史问答里老板已明确回答过的事实标"已证（老板 日期）"并列为"请确认"，不重问。不同 child 的事实不互相借用。
